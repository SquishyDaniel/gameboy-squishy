# Game Boy Squishy

[![GitHub](https://img.shields.io/badge/source-github?style=flat&logo=github&logoColor=cf9e91&label=github&color=cf9e91)](https://github.com/SquishyDaniel/gameboy-squishy)

### About (EN)

This is a website that fetches homebrew Game Boy games from the [HBGBDB](https://hbgbdb.playnation.org/) API, and displays them in an overview to easily select for play at your own leisure using [`wasmboy`](https://github.com/torch2424/wasmboy). 

#### Building

This project uses `npm` for its package management, and Vite for distribution.

```sh
$ npm install
$ npx vite
```
